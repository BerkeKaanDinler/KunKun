# Fixture verisi

Bölüm 2'de doldurulacak. İçerik politikası (Ü6–Ü10):

- `verses.json` — ~60 ayet. Metinler brief'teki beş uzunluk bandında
  (58 · 124 · 246 · 512 · 908 karakter) **yer tutucudur**, meal değildir.
  Her kart `ÖRNEK VERİ` künyesi taşır.
- `categories.json` — 160 kategori, **gerçek adlarıyla**.
- `families.json` — 16 aile, **gerçek adlarıyla**.
- `dhikr.json` — hazır set (md/11'den birebir, harekeli) + 3 örnek serbest zikir.

Künyeler `ÖRNEK 01:03` biçimindedir — gerçek sure/ayet referansıyla
karışması imkânsızdır. Çevirmenler `Örnek Meal A/B (yer tutucu)`.

Arapça alanlarda **yalnızca** tasarım dökümünden gelen gerçek metin bulunur;
uydurma Arapça üretilmez, veri yoksa alan boş bırakılır.
